The gentlest possible entry point. Students look at pictures of real collisions
and work out what happened, using the same reasoning a physicist uses, before
anyone mentions a dataset.

Last updated in 2017 and unmaintained, but the material is tutorial text and
classroom worksheets rather than code, so it has aged well. Check the display
links before class.

Often the right thing to run in the period before a data activity: students who
have seen an event display understand what a row in a CSV file represents.
