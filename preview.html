First time here?

  1. You do not need to know any particle physics to start. Several activities are written for students who have never heard of a muon, and a few need no computer at all.
  2. You do not need permission or an account. Everything indexed here is openly licensed. Copy it, cut it up, rewrite it for your class.
  3. Start smaller than you think. Most people who try to run a full analysis in week one give up. A twenty-minute event display activity that works is worth more than a three-week project that stalls.

Which data should I use?

Every CMS dataset is documented on the CERN Open Data Portal, and we do not duplicate that here. What is missing there is a way to answer the question people actually arrive with: given what I want to do, where do I start?

Reference, not tutorial

The CMS Open Data Guide is the authoritative description of formats, objects, and corrections. Treat it as a dictionary: excellent when you know the word you are looking up, hard going if you are trying to read it front to back. Come here to find out which page you need, then go there.

Add something to the index

If you have built an activity, translated one, or found a good one that is not listed, we want it here. You do not have to host it with us and you do not have to hand it over — the index points at wherever it already lives.

The two-minute way

Fill in the form

A short GitHub issue form asks for the same handful of fields you see on every resource page. A maintainer turns it into a record. You need a GitHub account but nothing else. If you would rather not, email cms-dpoa-coordinator@cern.ch and we will do the typing.

The direct way

Add one file to _resources/ and open a pull request. The file is YAML front matter followed by a few paragraphs of description. Automated checks will tell you if a field is missing or a term is not in the vocabulary, so you do not need to memorise the schema. Copy an existing record and edit it.

What we will and will not list

  • It has to be openly available, with no login and no fee.
  • It has to use CMS open data, or teach something you need in order to use it.
  • It does not have to be finished, polished, or maintained. Unmaintained material is labelled as such and stays listed, because a rough activity someone can find beats a perfect one they cannot.
  • We will not rewrite documentation that already exists elsewhere. If the Portal or the Guide covers it, we link to it.

Tell us how it went

The most useful thing you can add is not a new activity but a paragraph about running an existing one: what you cut, what confused students, how long it really took. Share that here.
